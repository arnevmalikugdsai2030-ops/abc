# Sample Benchmark Dataset Directory

This directory stores sample benchmark datasets generated by `scripts/generate_benchmark.py`.

## Structure:
- `tasks.jsonl`: Public benchmark records containing `sample_id`, `task_type`, `prompt_text`, and `image_rel_path`.
- `ground_truth.jsonl`: Private ground-truth keys containing `sample_id`, `true_answer`, `ray_coordinates`, and `proof_reason`.
- `images/`: High-resolution PNG blind inspection diagrams provided to the vision model.
- `debug_images/`: (Optional) Diagnostic images with optical rays drawn for human inspection.
